🍽️ Roots & Recipes

Roots & Recipes is a modern food ordering website designed for PG tenants and residents to easily order meals, snacks, and beverages.
The platform allows customers to select food, pay via UPI, and send the order directly to WhatsApp while automatically storing order data in Google Sheets.

🚀 Features

📱 WhatsApp Order System – Orders are sent directly to the kitchen via WhatsApp.

📊 Google Sheets Integration – All orders are automatically stored for tracking.

🍛 Daily Thali System – Affordable meal option for PG tenants.

💳 UPI QR Payment – Customers scan QR and enter UTR for payment confirmation.

📄 Downloadable Menu – View and download the full menu as PDF.

🏠 Room Enquiry System – Send PG or apartment enquiries via WhatsApp.

🎨 Premium UI Design – Elegant layout with animations and responsive design.
